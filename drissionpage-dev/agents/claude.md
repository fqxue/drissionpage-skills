# DrissionPage 开发

基于统一中文参考文档的 DrissionPage 开发协作技能；默认先看实战示例和栏目文档，只有在维护上游仓库或文档不足且明确卡住时才例外核对源码。

## 使用指引

使用 `drissionpage-dev` 处理 DrissionPage 脚本编写、文档检索、页面调试，或上游仓库维护任务。

默认流程：

1. 先看 `references/docs-map.md`
2. 再读：
   - `references/docs/实战示例/`
   - `references/docs/入门指南/`
   - `references/docs/`
3. 需要浏览器诊断时优先配合 MCP
4. 源码和 `.pyi` 不是默认入口，只在允许的例外场景下最小范围核对

建议优先复用示例中已验证的写法。详细规范见 [SKILL.md](../SKILL.md)。
