# 🌠 星巴克图片下载

本示例演示 `download()` 方法的使用。

## ✅️️ 页面分析

目标 URL：https://www.starbucks.com.cn/menu/

目标：下载所有产品图片，并以产品名命名。

按 `F12` 打开开发者工具，可以看到每个产品图片包含在 `class` 属性为 `preview circle` 的 `div` 元素中。图片 URL 隐藏在 `div` 元素的 `style` 属性中。产品名位于该 `div` 元素之后的兄弟元素中。

---

## ✅️️ 编码思路

根据网页结构，获取所有 `class` 属性为 `preview circle` 的元素，遍历它们，提取图片路径和产品名，然后执行下载。

由于该网页结构简单，不使用 JavaScript 生成内容，可以直接用数据包模式访问。

---

## ✅️️ 示例代码

```python
from DrissionPage import SessionPage
from re import search

# 创建 session 页面对象
page = SessionPage()
# 访问目标网页
page.get('https://www.starbucks.com.cn/menu/')

# 获取所有 class 属性为 'preview circle' 的元素
divs = page.eles('.preview circle')
# 遍历这些元素
for div in divs:
    # 使用相对定位获取当前 div 的下一个兄弟元素并获取其文本
    name = div.next().text

    # 从 div 元素的 style 属性中提取图片 URL 并拼接
    img_url = div.attr('style')
    img_url = search(r'"(.*)"', img_url).group(1)
    img_url = f'https://www.starbucks.com.cn{img_url}'

    # 执行下载
    page.download(img_url, r'.\imgs', rename=name)
```

> **提示**：无需手动创建 `imgs` 文件夹，`download()` 方法会自动创建。

---

## ✅️️ 要点说明

- **`download()` 方法**：内置非法字符过滤，自动处理文件名中的 `/` 等非法字符
- **文件名冲突**：遇到重名文件时，`download()` 提供三种选项：`skip`（跳过）、`overwrite`（覆盖）、`rename`（重命名加序号）
- **返回值**：`download()` 返回下载文件的绝对路径，方便后续使用
- **相对定位**：`div.next()` 获取下一个兄弟元素
- **对象选型**：网页结构简单时使用 `SessionPage`，无需启动浏览器
