# DrissionPage 开发

基于统一中文参考文档的 DrissionPage 开发协作技能；优先参考实战示例，其次各栏目文档，非必要不阅读源码。

## 使用指引

使用 `drissionpage-dev` 处理当前仓库中的 DrissionPage 代码、文档或调试任务。

编写 DrissionPage 代码时必须严格参考实战示例的代码风格：

- `references/docs/实战示例/` — 实战示例（最优先）
- `references/docs/入门指南/` — 入门指南与入门示例（其次）
- `references/docs/` — 各栏目文档（补充）
- 源码 — 非必要不阅读，仅在文档与实际行为明显不符时才酌情核对

不允许偏离示例已验证的写法。详细规范见 [SKILL.md](../SKILL.md)。
