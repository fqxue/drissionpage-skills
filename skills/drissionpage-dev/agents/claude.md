# DrissionPage 开发

基于源码、示例、docs_zh 与 docs_en 的 DrissionPage 开发协作技能。

## 使用指引

使用 `drissionpage-dev` 处理当前仓库中的 DrissionPage 代码、文档或调试任务。

编写 DrissionPage 代码时必须严格参考 demos 示例的代码风格：

- `references/docs_en/demos/` — 实战示例（最优先）
- `references/docs_en/get_start/examples/` — 入门示例（最优先）
- `references/docs_zh/` — 中文文档（其次）
- `references/docs_en/` — 英文文档其余文件（补充）

不允许偏离 demo 已验证的写法。详细规范见 [SKILL.md](../SKILL.md)。
