# 🌠 豆瓣图书封面下载

本示例演示如何使用浏览器直接保存图片，无需重新下载，直接从缓存读取并保存。

这是本库的一大亮点功能：不需要任何 UI 操作，也不需要重新下载图片，而是直接读取浏览器缓存中的图片并保存，使用非常方便。

## ✅️️ 页面分析

目标 URL：[https://book.douban.com/tag/小说](https://book.douban.com/tag/%E5%B0%8F%E8%AF%B4)

按 `F12` 打开开发者工具，可以看到每本书包含在 `class` 属性为 `subject-item` 的元素中。可以批量获取这些元素，再从中获取 `<img>` 元素来保存图片。

---

## ✅️️ 编码思路

为了演示元素对象的 `save()` 方法，我们使用浏览器操作将图片文件保存到本地 `imgs` 文件夹。

---

## ✅️️ 示例代码

以下代码可以直接运行。

```python
from DrissionPage import ChromiumPage

# 创建页面对象
page = ChromiumPage()
# 访问目标网页
page.get('https://book.douban.com/tag/小说?start=0&type=T')

# 采集 4 页
for _ in range(4):
    # 遍历当前页面所有书籍
    for book in page.eles('.subject-item'):
        # 获取封面图片对象
        img = book('t:img')
        # 保存图片
        img.save(r'.\imgs')

    # 点击下一页
    page('后页>').click()
    page.wait.load_start()
```

---

## ✅️️ 要点说明

- **`save()` 方法**：直接从浏览器缓存保存图片，无需重新发起网络请求
- **元素定位**：使用 `.subject-item` 按 class 批量获取书籍元素，用 `t:img` 按标签获取子元素
- **翻页模式**：点击"后页>"按钮后调用 `wait.load_start()` 等待页面加载
