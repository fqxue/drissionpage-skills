# 🌠 猫眼电影 TOP100 采集

本示例演示如何使用浏览器进行数据采集。

## ✅️️ 采集目标

目标 URL：[https://www.maoyan.com/board/4](https://www.maoyan.com/board/4)

采集内容：排名、电影名称、主演、上映时间、评分

---

## ✅️️ 编码思路

按 `F12` 打开开发者工具，可以看到每部电影的信息都包含在 `<dd>` 元素中。因此可以批量获取所有 `<dd>` 元素，遍历它们并获取每部电影的信息。

---

## ✅️️ 示例代码

以下代码可以直接运行。

注意这里使用了 recorder 对象，详情参见 [DataRecorder](http://g1879.gitee.io/datarecorder)。

```python
from DrissionPage import ChromiumPage
from DataRecorder import Recorder

# 创建页面对象
page = ChromiumPage()
# 创建记录器对象
recorder = Recorder('data.csv')
# 访问网页
page.get('https://www.maoyan.com/board/4')

while True:
    # 遍历页面中所有 dd 元素
    for mov in page.eles('t:dd'):
        # 获取所需信息
        num = mov('t:i').text
        score = mov('.score').text
        title = mov('@data-act=boarditem-click').attr('title')
        star = mov('.star').text
        time = mov('.releasetime').text
        # 写入记录器
        recorder.add_data((num, title, star, time, score))

    # 获取下一页按钮，如果存在则点击
    btn = page('下一页', timeout=2)
    if btn:
        btn.click()
        page.wait.load_start()
    # 不存在则退出程序
    else:
        break

recorder.record()
```

## ✅️️ 要点说明

- **元素定位**：`t:dd` 按标签批量获取，`.score` 按 class 定位，`@data-act` 按属性定位
- **翻页模式**：使用文本匹配"下一页"+ `timeout=2` 判断是否存在下一页按钮
- **DataRecorder**：第三方记录工具，用于将采集数据写入 CSV 文件
