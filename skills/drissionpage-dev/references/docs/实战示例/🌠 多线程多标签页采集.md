# 🌠 多线程多标签页采集

本示例演示如何使用多线程同时控制浏览器的多个标签页进行数据采集。

## ✅️️ 页面分析

目标 URL：

- https://gitee.com/explore/ai
- https://gitee.com/explore/machine-learning

按 `F12` 打开开发者工具，可以看到每个标题元素的 `class` 属性为 `title project-namespace-path`，可以批量获取。

---

## ✅️️ 编码思路

虽然 Gitee 的开源项目列表可以用数据包模式（s 模式）采集，但这里使用浏览器模式进行演示，以展示多标签页操作能力。

使用 `ChromiumPage` 的 `get_tab()` 方法获取两个标签页对象，分别交给不同线程操作。

---

## ✅️️ 示例代码

以下代码可以直接运行。

注意这里使用了 recorder 对象，详情参见 [DataRecorder](http://g1879.gitee.io/datarecorder)。

```python
from threading import Thread

from DrissionPage import ChromiumPage
from DataRecorder import Recorder


def collect(tab, recorder, title):
    """采集方法
    :param tab: ChromiumTab 对象
    :param recorder: Recorder 对象
    :param title: 分类标题
    :return: None
    """
    num = 1  # 当前采集的页码
    while True:
        # 遍历所有标题元素
        for i in tab.eles('.title project-namespace-path'):
            # 获取某页所有仓库名称，记录到 recorder 中
            recorder.add_data((title, i.text, num))

        # 如果有下一页，点击
        btn = tab('@rel=next', timeout=2)
        if btn:
            btn.click(by_js=True)
            tab.wait.load_start()
            num += 1

        # 否则采集结束
        else:
            break


def main():
    # 创建页面对象
    page = ChromiumPage()
    # 第一个标签页访问 URL
    page.get('https://gitee.com/explore/ai')
    # 获取第一个标签页对象
    tab1 = page.get_tab()
    # 新建标签页并访问另一个 URL
    tab2 = page.new_tab('https://gitee.com/explore/machine-learning')
    # 获取第二个标签页对象
    tab2 = page.get_tab(tab2)

    # 创建记录器对象
    recorder = Recorder('data.csv')

    # 使用多线程同时处理多个页面
    Thread(target=collect, args=(tab1, recorder, 'ai')).start()
    Thread(target=collect, args=(tab2, recorder, '机器学习')).start()


if __name__ == '__main__':
    main()
```

---

## ✅️️ 补充说明

本示例中，`page` 实际上就是一个标签页对象，等价于 `tab1`。

创建 `tab1` 对象只是为了可读性更好，实际上可以完全用 `page` 替代 `tab1` 的位置。

---

## ✅️️ 要点说明

- **多标签页管理**：`new_tab()` 创建新标签页，`get_tab()` 获取标签页对象
- **多线程安全**：不同线程操作不同标签页，互不干扰
- **函数文档字符串**：使用 `:param name: description` 格式的中文文档字符串
- **DataRecorder**：第三方记录工具，支持多线程写入
